01 · The framework

What eve gives you access to

An agent is a directory on disk. Instructions, tools, skills, connections, channels, sandboxes, subagents, and schedules are files — eve compiles and runs them as a durable service.

Core

Instructions

Always-on system prompt: identity, standing rules, constraints. Short and stable.

Core

Tools

Typed actions in your runtime — APIs, memory writes, approvals for irreversible work.

Core

Skills

On-demand procedures loaded when relevant. Progressive disclosure, not prompt bloat.

Reach

Channels

HTTP, Slack, Discord, Telegram, Twilio SMS, Photon iMessage, GitHub, Linear, web chat, and more.

Reach

Connections

MCP and OpenAPI services — CRM, Notion, Linear, GitHub — credentials never exposed to the model.

Runtime

Sandbox

Isolated shell + /workspace filesystem per session. Seed files, network policy, Vercel Sandbox.

Runtime

Durable sessions

Checkpointed turns, streaming, human-in-the-loop pause/resume across crashes and redeploys.

Scale

Subagents & remote agents

Specialists with their own tools, or another eve deployment as a child. Fan-out with Workflow.

Scale

Schedules

Cron prompts and handlers — digests, syncs, heartbeats that wake the agent without a human ping.

Quality

Evals

Scored checks against real sessions. Gate regressions when prompts or tools change.

Ops

Deploy & Agent Runs

Vercel Workflow + Sandbox. Inspect traces, tool calls, token usage in production.

Models

AI Gateway

Route provider/model strings through Vercel AI Gateway — Anthropic, OpenAI, and more.

Coding harnesses build software. eve runs the business — wake, remember, connect, approve.

03 · Infrastructure to build out

Database, auth, privacy, workspace, agents

Session state and sandbox files are enough for cofounder experiments. Client-ready tenants need isolation, durable memory, and a control plane.

Database

Postgres for company memory across sessions: facts, decisions, entities, tenant scope. Session defineState stays short-term; sandbox stays scratchpad.

  • InsForge · if DX wins
  • Supabase / Neon · next to Vercel
  • RLS · tenant_id

Authentication

Replace placeholder HTTP auth. Channel allowlists (who can text). Vercel Connect for OAuth connectors. Principals on ctx.session.auth for dynamic instructions and tools.

  • OIDC / Auth.js / Clerk
  • iMessage allowlist
  • Connect · Slack GitHub CRM

Security & privacy

Tenant isolation, least-privilege tokens, approval gates on irreversible actions, know model/provider retention, audit tool calls, retention/export for clients.

  • Approval · always()
  • Secrets · env only
  • Sandbox · network policy
  • Disclosure · non-owners

Agent Workspace

Control plane: company context, live agent status, SOPs, skills. Eve is the runtime; the workspace is where operators see what agents are doing — and where CRM / PM data lands for agents to work from.

  • Context hub
  • Status / activity
  • Pentridge MCP

Flexibility

Filesystem-first means new capability = new file. Dynamic instructions/tools per tenant. Add channels without rewriting the brain. Skills for procedures; tools for actions; workflows for repeatable paths.

  • defineDynamic
  • Remote agents
  • Extensions

Other agents & surfaces

Subagents and remote eve deployments talk to each other. Same brain, many doors: Slack, SMS, Instagram/Messenger adapters, web chat, coding agents via MCP. Platforms like Buzz or Grok bots become additional surfaces — not a second company brain.

  • Subagents
  • Remote agents
  • MCP bridges
  • Multi-surface
